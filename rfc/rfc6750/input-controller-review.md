# RFC 6750 번역 검토 메모

검토 완료: 2026-10-31. 비공식 AI 한국어 번역이며 규범의 기준은 공식 영문 원문입니다.

- 321개 번역 대상 전체를 직접 대조했습니다. 암호학적 키를 암호화 키로 좁혀 옮긴 두 표현과 페이지 경계의 문장 연결을 수정했습니다.
- 조건·부정·행위 주체·권고와 의무·용어·구역 경계를 확인했습니다. 구역 검증, 전체 포함 범위 검증, 조립, 최종 QA가 모두 통과했고 경고는 없습니다.
- 승인 번역의 용어 첫 사용 정규화·보호 토큰 복원 후 실제 HTML의 321개 대상과 19개 번역 속성을 별도로 대조했습니다. 차이가 없었습니다. 이 실행의 추가 검증이지 플러그인의 일반 웹 QA 공백을 고쳤다는 뜻은 아닙니다.
- 원문 대응 구간 10곳과 전체 데스크톱 화면을 직접 확인했습니다. 408개 원문 블록의 대응 순서가 같고 번역 본문의 숨김·가로 넘침은 없었습니다. 모바일에서도 도식 양 끝의 가로 스크롤과 줄이 나뉜 참고문헌 URL을 직접 확인했습니다.

코드·HTTP/ABNF 예제 10개, 고정폭 도식 1개와 도식 안의 영문, 원본 페이지 표시·저자 연락처 등 고정 메타데이터는 원문 그대로 보존했습니다. 본문은 한국어 길이에 맞춰 줄바꿈하고 기술 용어는 영문을 유지합니다. 모바일에서는 긴 코드와 도식 영역을 가로 스크롤할 수 있습니다.

2012년 원문의 TLS 보급 현황·쿠키 설명을 최신 권고로 바꾸지 않았습니다. 현대적인 적용 지침은 다음 RFC 9700 번역과 구분해 읽어야 합니다. 제품 코드·검사 규칙·원문을 변경하지 않았습니다.

최종 번역은 `index.html`, 자동 검토는 `review-report.md`, 출처·처리 이력은 `manifest.json`입니다.
