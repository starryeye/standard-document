# RFC 9126 원문·번역판 직접 검토 — 완료

2026년 11월 24일. [공식 Datatracker 발행본](https://datatracker.ietf.org/doc/html/rfc9126)과 실제 읽기용 HTML을 직접 대조했다. 한국어판은 2021년 9월 문서의 비공식 AI 번역이며, 현재 구현 규칙은 공식 규격과 그 업데이트가 우선한다.

## 의미와 구조

- 초록, §1–10, 감사의 말, 저자 연락처까지 확인했다. 원문의 문서 본문에 속한 번역 위치 272개를 최종 HTML과 짝지어 승인된 번역, 링크 대상, 접근성 속성과 대조했다. 원문 앵커 316개와 목차 내 이동 링크 31개를 확인했다.
- client의 일회 사용 의무와 서버의 재시도 예외, 정규 검증과 생략 조건, PAR의 `request_uri` 금지와 후속 요청에서의 사용, JAR의 인증 매개변수와 JWT 클레임 경계를 구분했다. [규범·예외 대조표](rule-ledger.md)에 절별 근거를 남겼다.
- HTTP·JSON 예제 10개는 원문과 텍스트·들여쓰기·줄바꿈이 일치한다. RFC 번호, 공개 예제 식별자, 등록 문자열과 과거 참고 문헌 버전을 바꾸지 않았다.
- §2에서만 [RFC 10070 §5](https://www.rfc-editor.org/rfc/rfc10070.html#section-5)의 현재 audience 규칙을 별도 편집 안내로 표시했다. [RFC Editor 정오표](https://errata.rfc-editor.org/search/?rfc_number=9126)의 보고 상태 항목 세 건은 승인된 본문 변경처럼 섞지 않았다.

## 화면

- 1440·768·390px에서 원문과 읽기용 HTML 전체를 확인했다. 본문과 제목의 위계, 문단 간격, 목록·정의 항목, 참고 문헌, 원문 페이지 표기가 잘리지 않는지 확인했다. 읽기판의 본문과 행 높이는 1440·768px에서 18/31.5px, 390px에서 16/28px이다. Datatracker 원문의 390px 본문은 약 8.6px였다.
- 긴 HTTP·JSON 예제는 원문 줄을 유지한다. 모바일에서 예제 10개 각각을 오른쪽 끝까지 스크롤해 확인했으며 페이지 전체에는 가로 스크롤이 없다. 일부 매우 긴 메타데이터 이름은 좁은 정의 항목 안에서 줄바꿈되며, 실제 값은 그대로다.
- 공개판에서는 원문에서 굵게 표시한 BCP 14 키워드 45곳에 해당 강조를 복구했다. 별도 §2 안내와 표시용 클래스만 제거하면 두 공개판 안의 번역 본문은 승인된 HTML과 바이트 단위로 일치한다.
