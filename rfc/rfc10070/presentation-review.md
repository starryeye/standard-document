# RFC 10070 읽기판 표시 수정 검수

직접 검토에서 나온 두 표시 문제를 반영했다. 번역을 다시 돌리지 않았고 기존 승인본과 예제는 수정하지 않았다.

- 원문의 BCP 14 표시 34개를 대응하는 한국어판 위치에서 다시 굵게 표시한다. 원문에서 강조하지 않은 단어나 다른 문서는 바꾸지 않는다.
- 가로로 넘치는 예제에는 바로 위에 ‘좌우로 스크롤해 전체 예제 보기’가 나타난다. 예제가 들어맞는 폭에서는 안내가 표시되지 않는다. 안내는 코드 밖에 추가되므로 복사하는 코드·줄바꿈·공백에 포함되지 않는다.

블로그와 보관판에서는 승인된 동일 본문을 그대로 넣고 [이 문서 전용 표시 스타일](assets/presentation-r2.css)을 별도로 불러온다. [공개 출력의 해시](publication.json)는 이 래퍼와 스타일을 구분한다. [승인된 원래 HTML](reviewed.html), 본문 조각, 매니페스트와 읽기판 기본 스타일은 기존 그대로다. 새로운 스크립트를 쓰거나 CSP를 변경하지 않았다. 원문에서 상속된 §3·§4의 역사적 교차 참조도 변경하지 않았다.

배포 전 Chromium에서 두 사이트 각각 320, 390, 414, 480, 525, 600, 601, 640, 690, 768, 1000, 1440px를 검사했다. 모든 폭에서 강조 위치 34개, 예제 6개의 텍스트 및 가로 스크롤 가능 범위, 안내 표시 조건, 페이지 전체 가로 넘침 없음, 승인 본문 일치를 확인했다. 390px에서는 블로그 예제 6개, 보관판 예제 4개에 근접 안내가 보이고, 두 사이트의 768px 및 1440px에서는 코드가 모두 들어맞는다. §4의 굵기, 붙은 안내, 가로로 끝까지 간 예제와 목차 이동을 실제 화면에서 확인했다. 컨테이너 쿼리를 지원하지 않는 브라우저에서는 상단에 있던 스크롤 안내가 남는다.
