# RFC 6749 번역 검토 메모

검토 완료: 2026-10-31. 비공식 AI 한국어 번역입니다. 규범의 기준은 공식 영문 원문입니다.

- 번역 대상 977개 전체를 원문과 직접 대조했습니다. 용어·조건·부정·행위 주체·권고와 의무·구역 경계를 확인했습니다.
- 노출 대상의 모호함, 권고를 의무처럼 옮긴 표현, 일부 문체와 메뉴 표현을 수정했습니다. URL은 바꾸지 않고 괄호 배치를 다듬었습니다.
- 구역별 검증, 전체 포함 범위 검증, HTML 조립, 최종 QA가 모두 통과했습니다. 선택 자산 경고는 없습니다.
- 문서 전체 용어 정규화·보호 토큰 복원 후, 승인 번역과 실제 HTML의 977개 번역 대상·18개 번역 속성을 별도로 대조했습니다. 차이가 없었습니다. 이 실행의 추가 검증이며, 플러그인의 일반 웹 QA 공백을 수정했다고 주장하는 것은 아닙니다.
- 전체 데스크톱 화면을 연속 검토하고 원문 대응 구간 10곳을 나란히 확인했습니다. 1,849개 원문 블록의 대응 순서가 같았고, 번역 본문 블록의 숨김·가로 넘침은 없었습니다. 모바일 도식 6개는 좌우 끝을 직접 확인했습니다.

## 보존 범위와 주의점

코드 예제 46개, 고정폭 도식 6개와 도식 안의 영문, 원본 페이지 머리말·꼬리말 등 고정 배치는 원문 그대로입니다. 모바일에서는 긴 코드·도식을 해당 영역 안에서 가로 스크롤하여 읽습니다. 본문은 한국어 길이에 맞춰 줄바꿈합니다. 기술 용어는 영문을 유지하고 최초의 적용 가능한 위치에 한국어 풀이를 제공합니다.

2012년 원문의 설명을 현재 보안 권고로 고쳐 쓰지 않았습니다. 최신 권고는 이어서 번역하는 RFC 9700과 구분해 읽어야 합니다.

원문 표현이 애매한 세 곳은 임의로 정정하지 않았습니다.

- 1절의 “third party's password”: 원문 표현을 그대로 옮겼습니다. 문맥은 제3자와 공유한 비밀번호를 설명합니다.
- 3.2.1절의 “authentication code”: 원문에 따라 인증 코드로 옮겼습니다. 주변 문맥은 authorization code를 다룹니다.
- 4.1.4절의 비문은 client 인증 실패 또는 요청이 유효하지 않은 경우라는 문맥으로 옮겼습니다.

최초 QA에서 실패한 초안은 별도 `-qa-failed-attempt0` 폴더로 보존했습니다. 최종 번역은 현재 폴더의 `index.html`, 자동 검토는 `review-report.md`, 출처·처리 이력은 `manifest.json`입니다. 제품 코드·검사 규칙·원문은 변경하지 않았습니다.
