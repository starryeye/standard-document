# RFC 6749 — 0.10.2 원문 대조 후속 편집 검토

2026-11-06. 설치된 supertranslator0.10.2로 새 실행 폴더에 재생성했습니다.

## 이번 변경

- RFC6749 §6에서 confidential 조건과 client credentials 조건 사이에 남았던 문단 경계를 연결했습니다.
- RFC9700 §2.6은 http redirection URI 금지 범위와 native-loopback 예외를 명확히 읽히도록, §4.5.3.2는 nonce 검증 및 성공 전 모든 token 사용 금지를 자연스러운 한국어로 AI가 직접 다듬었습니다.
- 검토된 목록 항목에 올바른 상위 목록을 제공했습니다. 중간의 본문·제목·코드나 원문의 위장 속성을 목록 항목으로 처리하지 않습니다. 기존 목록 소유 관계도 유지합니다.
- client/resource owner/authorization server 등 CS·보안 전문용어를 영어로 유지했습니다. 기계 번역·전체 재번역은 하지 않았습니다.

## 검증과 범위

- 이 문서의 누적 명시적 AI 교정은 1건이며, 이번에 추가한 것은 0건입니다. 입력 해시·원문·교정문·검토 근거는 [reader-review.json](reader-review.json)에 있습니다.
- 보존 블록 1033개를 독립 비교했습니다. 명시한 연결·교정 외에는 본문이 같고 코드·도식·ID·링크 목적지/라벨도 유지됩니다.
- 1440/768/390px 블로그 검사에서 18/18/16px 본문, 유효한 목차, 목록 소유권, 가로 넘침/깨진 이미지 없음이 확인됐습니다. 첫 화면과 변경 구간의 실제 화면도 직접 확인했습니다.
- 배포된 플러그인·설치된 실행 패키지의 파일을 대조했고, 실제 설치 런타임의 결과가 검토한 후보 렌더 바이트와 정확히 일치합니다. 새 시각 해시로 최종 QA를 통과했습니다.
- [설치·재생성 증거](regeneration.json), [QA](browser-qa.json), [시각 검토](visual-review.json), [입력 검토](input-review-report.md), [직전 검토](previous-reader-v0.10.1-review.md).
