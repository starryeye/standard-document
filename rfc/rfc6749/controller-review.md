# RFC 6749 — 0.10.1 원문 대조 편집·구성 검토

2026-11-05. 설치된 supertranslator 0.10.1으로 새 실행 폴더에 재생성했습니다.

## 변경과 보존

- 영어 명사(client, resource owner, authorization server 등)는 유지했습니다. 기계 번역이나 전면 재번역은 하지 않았습니다.
- 원문 대조 AI 문장 교정: 1건. 각 교정의 원문·입력 해시·교정문·의미 검토 근거를 [reader-review.json](reader-review.json)에 기록했습니다.
- 교정은 규범 키워드의 비문 배치 또는 불필요한 우회 표현만 바로잡습니다. English/numeric atoms, 코드, 링크 목적지·라벨은 바뀌지 않습니다.
- 목차는 실제 절로 이동하는 접힌 계층형 목차입니다. 원래 인쇄 목차와 페이지 번호는 말미 원문 표기에서 확인할 수 있습니다.
- 출판 정보는 문서 정보에서 펼쳐 볼 수 있습니다. 독립본 제목은 유지하고, 자체 제목이 있는 블로그에서만 중복 문서 제목을 숨겼습니다.
- 문단 ¶ 링크는 평상시 흐리게 표시하고 키보드 포커스·호버 시 선명해집니다. 기존 접근성 이름과 목적지는 유지합니다.

## 검증

- 설치된 플러그인과 실행 패키지 파일 45개 바이트 일치. 실제 export-reader / qa-reader 명령 실행.
- 보존 블록 1034개를 독립적으로 비교했습니다. 명시한 문단 연결·AI 교정 외에는 내용이 같습니다.
- 기존 코드·도식의 pre 텍스트, 원래 ID, 링크 목적지와 라벨을 보존했습니다. 새 탐색 링크도 모두 유효합니다.
- 블로그 1440/768/390px에서 본문 18/18/16px, 가로 넘침·깨진 그림·깨진 목차 링크 없음. 새 제목부·목차·교정문과 독립본 실제 화면 표본을 직접 확인했습니다.
- 전체 자동 캡처는 제한 높이 실제 스크롤 타일을 사용합니다. 거대한 빈 뒷부분 스크린샷으로 승인하지 않았습니다.
- [자동 QA](browser-qa.json), [화면 승인](visual-review.json), [설치·재생성 증거](regeneration.json).
