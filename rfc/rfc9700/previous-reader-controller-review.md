# RFC 9700 읽기용 편집 검토

2026-11-03. supertranslator 0.9.0으로 기존 AI 번역을 재조립했습니다. 새 기계 번역이나 전면 재번역은 하지 않았습니다.

## 원문·번역 보존

- 선택한 원문 영역의 본문과 코드·도식 전체를 새 본문과 비교했습니다. 공백 정규화를 제외하면 내용이 같습니다.
- ID·앵커·링크·그림·코드·도식의 보존 검사를 통과했습니다. 숫자와 규범 키워드를 바꾸지 않았습니다.
- 원문 출판 정보·반복 페이지 표기 1개는 삭제하지 않고 말미의 접힌 영역으로 옮겼습니다.
- 페이지 경계의 연결 후보를 원문과 대조해 실제 이어지는 문단 0곳만 연결했습니다. 다른 문단·목록·정의 항목은 합치지 않았습니다.

## 구성·화면

- 독립 읽기용 본문: PC 18px / 모바일 16px, 줄 높이 1.75, 최대 본문 폭 768px.
- 블로그: 기존 Minimal Mistakes 다크 테마·프로필·목록을 유지하고 번역 전문을 삽입했습니다. 1440/768/390px에서 본문 크기와 페이지 가로 넘침을 검사했습니다.
- PC·모바일 블로그 전체를 실제 스크롤한 번호별 타일의 연속 시트로 확인했습니다. 독립 읽기형은 전체 영역 자동 검사와 실제 화면 표본 대조를 함께 사용했습니다.
- 초대형 스크린샷의 빈 뒷부분은 증거로 사용하지 않았습니다. 3000px 이하 실제 스크롤 타일로 다시 캡처했습니다.
- 모바일의 긴 참고문헌 라벨은 설명 위로 배치해 설명 열이 좁아지는 것을 방지했습니다.
- 코드와 도식은 고정폭과 원래 줄바꿈을 유지하고 해당 영역 안에서 가로 스크롤합니다. 문서 자체는 가로로 넘치지 않습니다.
