# RFC 9700 번역 직접 검토

대상: [RFC 9700 — Best Current Practice for OAuth 2.0 Security](https://datatracker.ietf.org/doc/html/rfc9700/), 2025년 1월 발행본. 비공식 한국어 번역입니다.

## 결과

- AI가 16개 구역의 825개 번역 단위를 직접 번역했습니다. 기계 번역 서비스는 사용하지 않았습니다.
- 마스터가 전체 825개 원문·번역 쌍과 실제 인접 구역 경계를 대조했습니다. 의미, 조건·예외·규범 강도, 한국어 자연스러움, 용어, 경계 연결, 보호 항목의 여섯 차원을 검토했습니다.
- `MUST`가 한국어 문장 사이에 어색하게 삽입된 네 문장을 같은 담당자가 한 차례 수정했습니다. 재검증과 원문 재대조를 통과했습니다.
- 전체 번역 검증, HTML 조립, 브라우저 QA가 모두 종료 코드 0으로 완료됐습니다. 자동 필수 발견 사항과 선택 자산 경고는 없습니다.
- 별도 출력 대조에서도 실제 HTML의 825개 번역 단위와 번역된 속성 56개가 승인된 번역의 용어 정규화·보호 항목 복원 결과와 일치했습니다. 검토 입력의 SHA256도 최종 출력 검사까지 동일했습니다.

## 중점적으로 대조한 내용

정확한 redirect URI 일치와 네이티브 앱 포트 예외, PKCE 지원 확인·downgrade 방어, public/confidential client의 차이, CSRF와 nonce의 한계, implicit grant의 조건부 비권고와 password grant의 금지, mix-up 공격의 서버·엔드포인트 구분, sender constraint와 audience restriction, refresh token rotation의 탐지 한계, HTTP 307/303, reverse proxy 헤더, postMessage 양방향 origin 검증을 확인했습니다. `MUST`, `SHOULD`, `MAY`를 같은 강도로 번역하지 않았습니다.

기술 용어는 플러그인의 웹 번역 정책에 따라 영어를 유지하고 문서 첫 사용에 한국어 풀이를 적용했습니다. 본문·제목·목차·참고 문헌·접근성 문구를 번역했으며, HTTP/JSON/JavaScript 예제 12개와 URL·프로토콜 식별자는 원문 그대로 보존했습니다. 예제는 실행하지 않았습니다.

## 화면 검토

원문과 번역의 동일 논리 위치 17개를 나란히 비교하고, 번역본 전체 데스크톱 화면 60,505픽셀 높이를 6개 연속 시트로 확인했습니다. 제목·목차·목록·인용·참고 문헌·연락처와 코드 예제가 문서 흐름에 맞게 남아 있습니다. 모바일에서는 코드 예제 12개의 양 끝과 주변 본문을 확인했습니다.

자동 브라우저 검사는 1440×900과 390×844에서 문서 가로 넘침, 깨진 이미지, 잘린 텍스트를 발견하지 않았습니다. 별도 검사에서 보인 숨김 요소 9개는 원본에도 동일하게 숨겨진 메타데이터 라벨과 중복 RFC 제목입니다. 데스크톱 본문 한 곳의 약 5픽셀 초과 수치는 본문 잘림이 아니라 문단 끝 `¶` 링크의 여백이며, 실제 화면에서도 글이 잘리지 않습니다.

## 원문 보존 및 한계

- 처음 RFC Editor 표현은 필수 CSS가 빈 응답으로 내려와 중단했습니다. 대신 공식 Datatracker의 동일 발행본을 사용했습니다. 84개 절의 전체 정규화 본문과 12개 코드 예제가 RFC Editor 원문과 같음을 확인했으며, 원문·검사 규칙을 수정하지 않았습니다.
- 2.5절의 `private_key_jwt)`와 4.10.1절의 `this) document`에는 원문부터 불필요한 닫는 괄호가 있습니다. 번역에도 보존하고 별도로 기록했습니다. 표준의 내용을 임의로 교정하지 않았습니다.
- OAuth 2.1의 개발 중 상태, 참고 규격 버전, 당시의 권고는 발행본의 맥락을 보존했습니다. 최신 상태로 다시 쓴 해설서가 아닙니다.
- Datatracker 원본의 스타일을 유지했습니다. 390픽셀 폭에서는 원본과 번역 모두 본문이 약 8.58px로 작아지므로, 편하게 읽으려면 데스크톱이나 브라우저 확대를 권합니다. 모바일 전용 독서 디자인으로 재편집한 결과물은 아닙니다.
- 현재 플러그인의 자동 QA만으로 일반 문장의 승인본 일치까지 보장되는 것은 아닙니다. 이번 실행에서는 마스터의 전체 의미 검토와 별도의 실제 출력 대조로 보완했습니다. 플러그인 코드 자체를 수정한 것은 아닙니다.

이번 문서까지 완료한 뒤 작업을 중단했습니다. RFC 6749·6750·9700 세 문서가 완료됐으며, 이후 13개 문서는 시작하지 않았습니다.
