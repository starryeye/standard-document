RFC 7009 — 번역자 주와 검토 요약

한국어 읽기판 · RFC Editor 공식 원문 · 영문 저작권 고지

2013년 발행본과 정오표

이 번역은 2013년 발행본을 기준으로 합니다. RFC Editor 정오표의 §2.1 EID 6663은 번역 검토 시점에 Reported(보고됨) 상태였으므로 본문에 반영하지 않았습니다.

§3 구현 참고 사항의 어색한 원문은 짧은 수명의 access token을 쓰면 철회가 반영될 때까지 걸리는 시간에 상한을 둘 수 있다는 문맥으로 해석했습니다. 모든 배포에서 즉시 철회를 보장한다는 뜻은 아닙니다.

JSONP와 TLS 관련 문구는 발행 당시의 규격 설명입니다. OAuth 2.0 보안 권고는 RFC 9700도 참고하세요.

검토 및 읽기판 구성

공식 영문과 최종판의 전체 내용을 비교했고, 규범 표현·조건의 강도와 세 화면 폭(1440·768·390px)을 확인했습니다. JSONP 위험 안내와 token endpoint 대응책은 원문의 권고 수준으로 바로잡았고, revocation endpoint에 적용되는 의무는 그대로 유지했습니다.

공개 후 재검수에서는 §5 보안 고려 사항의 대응책 문장 하나를 둘로 나누어 의무와 권고가 더 분명하게 읽히도록 다듬었습니다. 나머지 번역과 코드·표는 그대로입니다.

코드 예시·ASCII 표·참고문헌은 원문의 줄바꿈을 보존합니다. 반복되는 페이지 표시는 문서 말미에서 펼쳐 볼 수 있습니다. 비공식 AI 한국어 번역이며 해석에 차이가 있으면 공식 영문을 기준으로 합니다.
