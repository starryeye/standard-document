RFC 9068 — 번역자 주와 원문 대조

한국어 읽기판 · 번역 §4 해당 문단 · 공식 영문 원문

§4 오류 응답의 주체

공식 영문 발행본은 오류 처리 주체를 resource server로 적은 뒤, 바로 다음 문장에서 invalid_token을 포함할 응답을 authorization server의 응답이라고 적습니다. 번역은 두 표현을 원문대로 유지했습니다. 공식 정오표가 아니며, 오류 응답을 구현할 때는 이 문단이 인용하는 RFC 6750 §3.1도 함께 참고하세요.

원문 대조 범위

원문과 최종 읽기판의 275개 요소를 직접 대조했습니다. 필수 Claim, 서명 및 만료 검증, 규범 키워드의 강도를 점검했고, HTTP 요청과 JWT 예시는 줄바꿈을 포함해 원문 그대로 유지했습니다. 1440·768·390px에서 글자 크기, 문단과 목차, 모바일 코드 스크롤을 확인했습니다. 이 주석은 번역 본문을 변경하지 않습니다.
